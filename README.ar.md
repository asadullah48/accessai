# 👁️ منصة AccessAI: وكيل الوصف الصوتي الفوري وإتاحة الوصول الرقمي الشامل

> **إطار عمل متعدد الوكلاء يولّد أوصافاً صوتية فورية تتناسب مع فترات الصمت بين الحوارات، ويدقّقها آلياً وفق معايير WCAG 2.2 AAA و Section 508 و ADA Title III.**

[النسخة الإنجليزية / English README](./README.md)

---

## 🌟 المزايا الرئيسية

1. **فريق وكلاء متخصص**:
   - **`StreamAgent`**: تطبيع بيانات الإطار المُحلَّل — تنظيف العناصر المرئية، وترتيبها حسب الأهمية، وتحديد ميزانية فترة الصمت.
   - **`NarratorAgent`**: صياغة أطول وصف ممكن يتناسب مع فترة الصمت المتاحة، مع اختصاره تدريجياً عند الحاجة.
   - **`ComplianceAgent`**: تقييم خمسة معايير وإصدار درجة امتثال موزونة مع تفصيل لكل معيار.

2. **التدقيق محسوب وليس مفترضاً**: كل معيار يُحسب من بيانات الإطار والوصف المولَّد، وكل معيار قابل للفشل فعلياً.

| المعيار | آلية القياس | الوزن |
| :--- | :--- | ---: |
| **منع تداخل الحوار** | مدة النطق المقدّرة مقابل فترة الصمت المتاحة | 30 |
| **WCAG 1.2.5** الوصف الصوتي | التأكد من إنتاج مسار وصف غير فارغ | 25 |
| **WCAG 1.4.6** التباين المُحسَّن | حساب السطوع النسبي الحقيقي لألوان النص الظاهر | 20 |
| **WCAG 1.2.7** الوصف الصوتي الممتد | يُفعَّل فقط عند قِصَر فترة الصمت، ويتطلب إتاحة إيقاف ممتد | 15 |
| **ميزانية زمن الاستجابة** | قياس فعلي عبر `perf_counter` ويُعرض كما هو دون تعديل | 10 |

3. **سُلَّم الاختصار التدريجي**: عند قِصَر فترة الصمت تُحذف التفاصيل الأقل أهمية أولاً، ولا يُحذف الموضوع الرئيسي أبداً. وإذا كانت الفترة أقصر من الحد الأدنى للنطق، يُبلَّغ عن ذلك بصراحة عبر `fits_silence_gap: false` بدلاً من ادعاء النجاح.

4. **أوصاف صوتية مكانية (Spatial Audio)**: تحديد اتجاه الأحداث المرئية (الوسط، خارج الإطار يميناً أو يساراً، خلفية محيطة).

5. **استوديو تفاعلي ثنائي اللغة**: واجهة تدعم العربية (RTL) بالكامل، ومبنية وفق المعيار الذي تدقّقه: تسميات مرتبطة بكل حقل، ومناطق `aria-live` تُعلن النتائج، ورابط تخطٍّ للوحة المفاتيح، ومؤشرات تركيز واضحة، ونتائج مكتوبة نصاً لا باللون وحده، مع احترام تفضيل تقليل الحركة.

## 🛠️ التشغيل السريع

```bash
git clone https://github.com/asadullah48/accessai.git
cd accessai

pip install -e ".[dev]"
pytest -v

uvicorn accessai.server:app --host 127.0.0.1 --port 8015 --reload
```

- **الاستوديو التفاعلي**: <http://127.0.0.1:8015/>
- **توثيق OpenAPI**: <http://127.0.0.1:8015/docs>

## ⚖️ حدود المشروع

هذا **نموذج عملي لخط المعالجة** وليس نظام بث منشوراً في الإنتاج. التحديد الدقيق للحدود:

- **حقيقي ومُنفَّذ**: حسابات التباين وفق WCAG (مُتحقَّق منها مقابل الألوان الحدّية المنشورة `#767676` و `#595959`)، وتقدير مدة النطق، وسُلَّم الاختصار، وترميز SSML الآمن، والتقييم الموزون، وقياس زمن الاستجابة.
- **غير مُتضمَّن**: الرؤية الحاسوبية، واستخراج النصوص (OCR)، وتوليد الصوت. تُقدَّم العناصر المرئية والنصوص الظاهرة كمُدخلات لا كنتائج تحليل للصورة، ويُصدَر ترميز SSML لمحرك نطق خارجي دون تحويله إلى صوت.
